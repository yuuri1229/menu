# MEGURU（旧こんだて帖）

1週間の献立・買い物リスト・家の在庫・買い物の実績を、スマホで見やすく表示するサイトです。
Next.js の静的書き出しを GitHub Pages で配信し、Firebase Authentication のログイン（新規登録なし）で守ります。
iPhone のホーム画面に追加して、アプリとして使う前提の作りです（全画面表示、下タブ、安全領域の余白、開き直したときに日付を更新、タブの再タップで先頭へ）。

| 画面 | できること |
| --- | --- |
| 今日 | 次のごはん、炊飯や取り分けの段取りメモ、次の買い物、今週の食費、在庫の確認 |
| 献立 | 週ごとの朝・昼・夜。タップでメモ（【実績】・変更・段取り）と使う食材、「作った」の記録 |
| 買い物 | 買い物回ごとのリスト。店でタップすると「買った」として保存 |
| 在庫 | 状態（十分・残りわずか・切れた・要確認）の切り替え、魚介チェック、賞味期限 |
| 家計 | 週予算に対する食費、週ごとの推移、お店ごと、明細 |
| ノート | 週の「買い物リスト・予算」と前提条件（Markdown） |

## しくみ

```
Claude ──(scripts/db.mjs)──▶ Firestore ◀──(ログインして読み書き)── GitHub Pages のサイト
```

- データの置き場所は Firestore だけです。Claude（毎週土曜の献立づくり、レシートの記録など）は `scripts/db.mjs` で読み書きし、アプリはリアルタイムに反映します。
- アプリから書き換えられるのは「作った」「買った」「在庫の状態」の3項目だけです（`firestore.rules`）。電波がなくても押せて、つながったときに送られます。
- Firestore は `members` に登録したアカウントしか読めません。データは GitHub Pages の公開ファイルにもリポジトリにも含まれません。
- データの形は `scripts/schema.mjs` にあり、CLI は書き込む前にここで検査します。Claude 向けの手順は [CLAUDE.md](CLAUDE.md)。

設定の手順は [docs/SETUP.md](docs/SETUP.md) にあります。

## 開発

```sh
npm install
npm run dev                       # 本番の Firebase につながる（ログインが必要）
NEXT_PUBLIC_DEMO=1 npm run dev    # ログインなしのデモデータで画面を確認
npm test                          # データの形と Markdown 変換のテスト
npm run build                     # out/ に静的ファイルを書き出す
npm run db -- help                # データの読み書き（鍵が必要。CLAUDE.md を参照）
```

予算や米の扱いなど運用ルールは `src/lib/config.ts` にまとめています。
